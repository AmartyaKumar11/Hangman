# Hangman Game 🎮
## A simple Hangman game built using React and TypeScript. Test your word-guessing skills and have fun solving the mystery word!

# Features ✨
 - 🖥️ Built with React and TypeScript for robust and type-safe development.
 - 🎯 Dynamic gameplay with randomized words.
 - 🎨 Responsive design for an enjoyable experience across devices.
 - 🔢 Score tracking to keep you motivated.
 - ✏️ Customizable word lists for varied gameplay.
